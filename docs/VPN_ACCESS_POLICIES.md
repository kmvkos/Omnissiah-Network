# VPN v2 P5 — черновики политик (НЕ firewall)

Следующий изолированный этап после реестра защищаемых объектов.
`/vpn/access-policies` доступен только администратору и требует CSRF при POST.

Структура одного правила: применённый Cognitor → зарегистрированный
защищаемый объект (IPv4 /32 или CIDR) → TCP/UDP + один порт либо ICMP
без порта → allow/deny.

Реестр `vpn_v2_access_policy_drafts` независим от legacy
`AccessPolicyRule`, `PolicyGroup`, `FirewallRule`. Уникальна
комбинация источника, назначения, протокола и порта; конфликт
allow/deny для одной комбинации запрещён. Для ICMP в БД записывается
port=0, чтобы SQLite UniqueConstraint предотвращал дубликаты.

Состояние каждого правила: `draft`, никакого фактического применения.
Отдельная GET-страница предпросмотра только объясняет намерение и
показывает, относятся ли источник и назначение к разным Magos.
`routing_verified=false`, `firewall_installed=false`,
`apply_available=false`, `writes_performed=false`.

**Нельзя считать, что deny блокирует пакеты, а allow разрешает доступ.**
Без внедрения firewall объекты защищены лишь теми механизмами, которые
уже существовали до создания правила. Эта стадия не обеспечивает
default deny и не вызывает WireGuard, root-helper, mTLS, ip route или nft.

Будущая работа:

1. Read-only проверка фактических путей, обратного маршрута и интерфейсов
   на исходном и целевом Magos; запрет при неизвестном / асимметричном пути.
2. Безопасный проект nftables: отдельная таблица и цепочки под владением
   Omnissiah, default deny **только для контролируемого data-plane**,
   явные исключения управления, антиспуфинг Cognitor IP по wg0.
3. Root RPC транзакции с журналом, UUID, preflight under lock, dry-run,
   атомарным apply и откатом, сохранением после reboot и независимой
   проверкой реального трафика.
4. Показать desired/actual, журнал и статус применения (не смешивать с draft).

Deployment: только из feature branch на лабораторном стенде, после
снапшота ВМ и резервной копии БД. `control-update.sh` использует main
и для этих веток не подходит.
