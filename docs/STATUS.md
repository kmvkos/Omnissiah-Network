# Состояние при импорте

Дата подготовки: 12 октября 2026 года.

## Исходная версия

Взято основное рабочее дерево `NMC_WG/` из архива `NMC_WG(1).zip`.
По метаданным архива `src/app.py` обновлён 25 ноября 2025 года,
а основные файлы агента — 24 ноября 2025 года. Проверенные вложенные сборки
содержат более ранние версии этих файлов. Это даты файлов в архиве,
а не подтверждённая история Git.

## Что означает текущий этап

Есть значительная реализация сервера управления, агентов, WireGuard,
политик доступа, защищаемых объектов, mTLS и статистики.
Проект находится на этапе восстановления прототипа. Сквозная работа и
безопасность всех API по наличию исходников не подтверждены.

Исходники и исходные `requirements.txt` сохранены без исправления логики.
Изменена упаковка: добавлены README, `.gitignore`, `.env.example` и сборка
из текущего коммита Git. Устаревшие отчёты о завершённых исправлениях
не включены как актуальное руководство.

## Выявленные несоответствия

| Участок | Наблюдение | Следующий шаг |
| --- | --- | --- |
| Тесты | Импорты `nmc_core`, `nmc_utils` не соответствуют каталогам `omnissiah_core`, `omnissiah_utils`; mock-пути тоже требуют проверки | Обновить импорты и проверить смысл тестов |
| Зависимости | SSH-функции импортируют `paramiko`, которого нет в исходном списке сервера | Дополнить и проверить зависимости |
| Установка | `install.sh` применяет `pip3 install --user` | Проверить установку в отдельном venv |
| Запуск | `start.sh` и агент пытаются освобождать занятой порт остановкой процесса | Заменить на предсказуемую ошибку запуска |
| Авторизация | Встроенные начальные учётные данные; агент содержит маршрут установки зависимостей без обязательной проверки VPN IP | Проверить доступ ко всем управляющим API |
| Архитектура | Omnissiah участвует в конфигурации WireGuard; `src/app.py` содержит 14 836 строк | Сначала проверить сквозной сценарий, затем разделять модули |
| Документация | Часть старых инструкций указывает другие начальные пароли и несуществующий unit сервера | Использовать новые README и SETUP, сверять детали с кодом |

## Проверки и их границы

- Python-файлы выбранных исходников проверяются на синтаксис без их импорта.
- Shell-скрипты проверяются командой `bash -n`, без выполнения установки.
- Перенос исходников сверяется побайтно с выбранными файлами архива.
- Состав Git и сборки проверяется на отсутствие локальных секретов, баз,
  сертификатов, архивов, резервных копий и виртуальных окружений.
- Тесты не выполнялись: в среде импорта отсутствует `pytest`. Дополнительно
  статически выявлены устаревшие импорты, препятствующие сбору тестов.
- Сервер и агент не запускались; VPN, SSH-развёртывание, firewall и перезагрузка
  узлов требуют отдельного Linux-стенда.

## Критерий первого рабочего результата

Один Omnissiah и два Magos создаются с новой конфигурацией; туннель получает
handshake; выбранные подсети обмениваются разрешённым трафиком; запрещённый
трафик блокируется; сервер показывает фактически применённое состояние;
после перезагрузки узлов всё повторяется без ручного восстановления.
