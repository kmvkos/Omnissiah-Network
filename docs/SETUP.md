# Подготовка стенда

Основной способ установки — [развёртывание через Ansible](ANSIBLE.md).
Он устанавливает Python и зависимости, создаёт PKI и начальные записи узлов,
настраивает nginx и systemd и проверяет управляющий обмен.

Для первого стенда подготовьте Debian 13 amd64, одну ВМ Omnissiah и две Magos,
без рабочего стола. Нужны стабильные адреса, SSH и возможность получить права
root через sudo. До установки сделайте снимки ВМ.

Старые `install.sh`, `start.sh` и `agents/run.py` не являются проверенным способом
этого развёртывания. Они могут применять сетевые настройки, использовать
`pip --user`, создавать встроенную учётную запись и освобождать занятые порты
остановкой процесса. Новый playbook их не запускает.

Туннели, маршруты и политики доступа будем проверять следующим этапом.
Состояние работ: [STATUS.md](STATUS.md).
