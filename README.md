# Omnissiah Network

Система централизованного управления распределённой VPN-сетью на базе WireGuard.

- **Omnissiah** — сервер управления и веб-интерфейс.
- **Magos** — управляемые Linux-узлы с агентом и WireGuard.
- **Cognitor** — конечные VPN-клиенты.

Личный проект для собственной инфраструктуры. Текущий этап — восстановление и стабилизация прототипа.

Актуальные исходники из предоставленного архива и подробная документация подготавливаются в ветке `import/project-baseline` для добавления через Pull Request.
